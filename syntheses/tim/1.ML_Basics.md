## **I. HIÉRARCHIE : AI → ML → DL**

### **Intelligence Artificielle**

- Domaine large : règles, logique, heuristiques, ML, vision, NLP
- Pas de définition unique
- Question historique : **la pensée peut-elle être formalisée mathématiquement ?**

### **Machine Learning**

**Définition** : Un programme apprend d'une expérience **E** pour une tâche **T** selon une performance **P**, si P sur T s'améliore avec E.

**ML vs Statistiques** :

| **Statistiques** | **Machine Learning** |
| --- | --- |
| Comprendre, expliquer | Prédire, optimiser |
| Inférence | Généralisation |
| Modèles interprétables | Performance prédictive |

**Vision** : ML = statistique computationnelle orientée prédiction

### **Deep Learning**

- Réseaux de neurones profonds
- Succès récent : données massives + puissance calcul + algos améliorés
- Apprentissage de représentations hiérarchiques
- Couches profondes → structures abstraites
- Millions de paramètres

## **II. TROIS PARADIGMES D'APPRENTISSAGE**

### **1. Supervised Learning**

**Données labélisées** : D = {(x¹, y¹), ..., (xⁿ, yⁿ)}

- **x** : features (entrées)
- **y** : target (sortie, label)

**Objectif** : Apprendre f : X → Y

**Deux types** :

**Régression**

- Y ∈ ℝ (continu)
- Exemples : prix maison, durée hospitalisation

**Classification**

- Y ∈ {c₁, ..., c_k} (catégoriel)
- Exemples : chat/chien, espèce fleur, catégorie risque

### **2. Unsupervised Learning**

**Pas de labels** : D = {x¹, ..., xⁿ}

**Objectif** : Découvrir structures internes

**Tâches** :

- **Clustering** : regrouper observations similaires (K-means)
- **Réduction dimension** : PCA, autoencoders
- **Détection anomalies** : logs, fraudes
- **Règles association** : market basket

### **3. Reinforcement Learning**

**Agent interagit avec environnement** :

- Observe état → choisit action → reçoit récompense → environnement évolue

**Objectif** : Maximiser récompense cumulée future

**Caractéristiques** :

- Récompenses **différées** (pas immédiates)
- Signaux **bruités**
- Apprentissage par **interaction** (pas exemples fixes)

**Exemples** : robotique, jeux (AlphaGo), trading, contrôle autonome

## **III. DONNÉES EN SUPERVISED LEARNING**

### **Structure**

```
D = {(x¹, y¹), ..., (xⁿ, yⁿ)}
```

- **n** : nombre observations
- **p** : nombre features
- **x** ∈ ℝᵖ : vecteur features
- **y** : target

### **Types de features**

- **Numériques** : ℝ (température, prix)
- **Entières** : ℤ (nombre pièces)
- **Catégorielles** : sans ordre (couleur, genre)
- **Ordinales** : avec ordre (niveau éducation)
- **Binaires** : oui/non, 0/1

### **Encodage catégorielles**

**One-Hot Encoding**

Créer **k colonnes** pour k catégories

Couleur = {Rouge, Vert, Bleu}

| **Rouge** | **Vert** | **Bleu** |
| --- | --- | --- |
| 1 | 0 | 0 |
| 0 | 1 | 0 |

**Dummy Encoding**

Créer **k-1 colonnes** (plus économique)

| **Vert** | **Bleu** |  |
| --- | --- | --- |
| 0 | 0 | (Rouge = référence) |
| 1 | 0 |  |

### **Condition essentielle**

> **X et Y doivent être liés** sinon aucune prédiction fiable possible

## **IV. DATA GENERATING PROCESS**

### **Hypothèse fondamentale**

Les données sont générées par une **distribution P(X, Y) inconnue**

```
(x¹, y¹), ..., (xⁿ, yⁿ) ~ P(X, Y)
```

**On observe** : échantillon fini

**On veut** : apprendre la distribution sous-jacente pour généraliser

### **Hypothèse i.i.d.**

**i.i.d.** = independent and identically distributed

**Signification** :

- **Independent** : observations ne dépendent pas les unes des autres
- **Identically distributed** : tirées de la même distribution

**Limitations** :

- Séries temporelles : t dépend de t-1
- Données spatiales : corrélation géographique
- Mesures répétées sur même individu

**Malgré tout** : hypothèse souvent adoptée pour simplifier

### **Notations**

- **X, Y** : variables aléatoires (majuscules)
- **x, y** : réalisations observées (minuscules)
- **θ** : paramètres (fixes mais inconnus)

## **V. MODÈLES = FONCTIONS PARAMÉTRÉES**

### **Définition**

Un modèle est une **fonction** :

```
f_θ : X → ℝᵍ
```

**Dimension sortie g** :

- Régression : g = 1
- Classification : g = k (k classes)

### **Espace d'hypothèses H**

On ne cherche pas **toutes** les fonctions → on restreint à une **famille**

```
H = {f_θ : θ ∈ Θ}
```

**Exemples** :

- Toutes les fonctions linéaires
- Tous les arbres profondeur ≤ 5
- Tous les réseaux d'une architecture donnée

**Structural prior** : contrainte sur la forme de f (hypothèse a priori)

### **Paramétrisation**

Chaque modèle dans H est défini par un vecteur **θ** :

```
θ = (θ₁, θ₂, ..., θ_d)
```

**Transformation du problème** :

- Recherche d'une fonction

⬇️

- Optimisation d'un vecteur θ

**Apprendre = trouver le meilleur θ**

## **VI. EXEMPLES DE MODÈLES**

### **1. Linéaire univarié**

```
f(x) = θ₀ + θ₁·x
```

- θ₀ : intercept
- θ₁ : pente
- **θ ∈ ℝ²**

### **2. Quadratique bivarié**

```
f(x₁, x₂) = θ₀ + θ₁x₁ + θ₂x₂ + θ₃x₁² + θ₄x₂² + θ₅x₁x₂
```

- 2 features (x₁, x₂)
- **θ ∈ ℝ⁶**

### **3. RBF Network**

```
f(x) = Σᵢ αᵢ · φ(||x - cᵢ||)
```

- αᵢ : poids (hauteurs)
- cᵢ : centres
- φ : fonction gaussienne
- Combinaison de cloches gaussiennes

**Hyperparamètres** (fixés avant) :

- **K** : nombre de neurones
- Largeur gaussiennes

## **VII. HYPERPARAMÈTRES VS PARAMÈTRES**

|  | **Paramètres θ** | **Hyperparamètres λ** |
| --- | --- | --- |
| **Appris ?** | Automatiquement | Fixés avant |
| **Quand ?** | Pendant entraînement | Avant entraînement |
| **Exemples** | Poids, biais, coefficients | K, profondeur, learning rate |
| **Comment ?** | Optimisation (gradient) | Validation croisée |

**Exemples hyperparamètres** :

- Nombre de neurones K dans RBF
- Profondeur maximale arbre
- Learning rate descente gradient
- Coefficient régularisation λ

## **VIII. LEARNER (ALGORITHME D'APPRENTISSAGE)**

### **Définition**

Le learner trouve le meilleur modèle dans H

**Formellement** :

```
Learner : D × Λ → Θ
```

- **D** : données entraînement
- **Λ** : hyperparamètres
- **Θ** : paramètres optimaux

### **Mécanisme**

1. Fixer espace H
2. Choisir hyperparamètres λ
3. Optimiser paramètres θ sur données D
4. Retourner modèle f̂

### **Objectif**

Minimiser fonction de perte (loss) :

```
θ* = argmin_θ L(θ; D)
```

**Exemples loss** :

- **Régression** : MSE = (1/n) Σ (yⁱ - f_θ(xⁱ))²
- **Classification** : Cross-entropy, 0-1 loss

### **Distinction importante**

| **Modèle** | **Learner** |
| --- | --- |
| Définit **quoi** apprendre | Définit **comment** apprendre |
| Espace solutions (H) | Algorithme recherche |
| Ex : régression linéaire | Ex : gradient descent |

## **IX. PREDICT VS EXPLAIN**

### **Predict (Prédire)**

**Objectif** : Performance maximale sur nouvelles données

**Caractéristiques** :

- Focus sur généralisation
- Accepte "boîte noire"
- Mesure : précision, erreur, AUC

**Exemples** : recommandation, reconnaissance images

### **Explain (Expliquer)**

**Objectif** : Comprendre relation X → Y

**Caractéristiques** :

- Focus sur interprétabilité
- Quelles features sont importantes ?
- Comment influencent Y ?

**Exemples** : diagnostic médical, scoring crédit

### **Trade-off**

```
Interprétabilité ←→ Performance
```

- Modèles simples : faciles à interpréter, moins précis
- Modèles complexes : très précis, difficiles à interpréter

### **Pourquoi explication importante ?**

- **Confiance** : comprendre les décisions
- **Légalité** : RGPD impose "droit explication"
- **Sécurité** : éviter reverse engineering
- **Équité** : détecter biais discriminatoires
- **Débogage** : identifier erreurs modèle

**Techniques** : SHAP, LIME, attention maps, feature importance

## **X. PROCESSUS COMPLET SUPERVISED LEARNING**

### **Phase 1 : Construction**

1. Collecter données labélisées D
2. Choisir espace hypothèses H
3. Choisir hyperparamètres λ
4. Définir loss function L

### **Phase 2 : Apprentissage**

1. Utiliser learner pour optimiser θ
2. Obtenir modèle f̂ = f_θ*

### **Phase 3 : Prédiction**

1. Recevoir nouvelles données x_new
2. Prédire ŷ_new = f̂(x_new)

## **SYNTHÈSE ULTRA-RAPIDE**

### **1. Hiérarchie**

```
AI ⊃ ML ⊃ Deep Learning
```

### **2. Trois paradigmes**

- **Supervised** : (X, Y) labélisé → apprendre f : X → Y
- **Unsupervised** : X seul → découvrir structures
- **Reinforcement** : agent → action → récompense

### **3. Supervised = Deux tâches**

- **Régression** : Y ∈ ℝ (continu)
- **Classification** : Y ∈ {c₁, ..., c_k} (catégoriel)

### **4. Data generating process**

- Données ~ P(X, Y) inconnue
- **Hypothèse i.i.d.** : observations indépendantes même distribution

### **5. Modèle**

```
f_θ : X → Y
```

- Fonction paramétrée par θ
- H = {f_θ : θ ∈ Θ} = espace hypothèses

### **6. Structural prior**

Contrainte sur forme de f (ex : linéaire, polynomiale)

### **7. Hyperparamètres ≠ Paramètres**

- **Paramètres θ** : appris pendant entraînement
- **Hyperparamètres λ** : fixés avant entraînement

### **8. Learner**

Algorithme qui optimise θ :

```
θ* = argmin_θ L(θ; D)
```

### **9. Encodage catégorielles**

- **One-hot** : k colonnes
- **Dummy** : k-1 colonnes (plus économique)

### **10. Predict vs Explain**

- **Predict** : performance maximale
- **Explain** : interprétabilité
