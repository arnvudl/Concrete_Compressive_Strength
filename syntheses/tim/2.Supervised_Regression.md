## Le cadre général

La régression linéaire s'inscrit dans le cadre ERM classique : **Hypothesis Space + Risk + Optimization**. On fait ici deux choix précis : H = fonctions linéaires, et Loss = L2 (ou L1).

Le modèle : `ŷ = f(x) = θᵀx = θ₀ + θ₁x₁ + … + θ_p x_p`

θ contient les poids à apprendre, et y est une combinaison linéaire des features. Point important : le modèle est **linéaire en θ**, mais peut très bien être non linéaire en x si on ajoute des features transformées.

---

## La matrice design

Pour écrire tout ça proprement en vectoriel, on ajoute une constante 1 à chaque observation : `x̃ = (1, x₁, …, x_p)`, ce qui donne `ŷ = Xθ` avec X ∈ ℝ^{n×(p+1)}.

Chaque ligne de X = une observation, chaque colonne = une feature. Cette notation compacte permet d'utiliser le calcul matriciel pour tout résoudre d'un coup.

---

## Interprétation des coefficients

C'est une des grandes forces du modèle linéaire : **θ_j = effet marginal de x_j**. Si x_j augmente de 1, alors y augmente de θ_j, toutes choses égales par ailleurs (*ceteris paribus*). L'interprétation dépend néanmoins fortement des variables incluses dans le modèle.

---

## L2 Loss et le SSE

La loss quadratique : `L(y, f(x)) = (y − f(x))²`

Le risque empirique devient alors le **SSE (Sum of Squared Errors)** :

```
R_emp(θ) = Σ (yᶦ − θᵀxᶦ)²
```

Pourquoi L2 ? Parce que c'est convexe, différentiable partout, et que ça permet une optimisation simple avec un lien fort avec les statistiques classiques. Le modèle optimal = celui qui minimise le SSE.

Visuellement, on peut représenter R_emp(θ₀, θ₁) comme une **surface en forme de bol** dans l'espace des paramètres. Chaque point de cette surface = un modèle possible avec son SSE. Le fond du bol = le meilleur θ.

---

## Solution OLS

Propriété rare et précieuse : il existe une **solution analytique exacte**.

On dérive le SSE et on impose la condition stationnaire :

```
∂/∂θ ‖y − Xθ‖² = −2Xᵀ(y − Xθ) = 0
```

Ce qui donne les **équations normales** : `XᵀX θ = Xᵀy`

Et donc la **solution OLS** :

```
θ̂ = (XᵀX)⁻¹ Xᵀy
```

Condition : XᵀX doit être inversible → pas de colinéarité parfaite entre les features.

**Interprétation géométrique :** OLS = projection orthogonale de y sur l'espace colonne de X. Le résidu `y − Xθ̂` est orthogonal à toutes les colonnes de X.

---

## Propriétés statistiques

Sous hypothèses (données i.i.d., erreurs gaussiennes homoscédastiques, X non colinéaire) :

```
y = Xθ + ε    avec ε ~ N(0, σ²I)
```

On peut faire de l'inférence complète : p-values, intervalles de confiance, et le **R²** :

```
R² = 1 − SSE / SST
```

SSE = variance non expliquée, SST = variance totale. R² mesure la proportion de variance expliquée par le modèle.

---

## L1 Loss — robustesse aux outliers

On garde le même modèle, on change juste la loss : `L(y, f(x)) = |y − f(x)|`

C'est la **LAD (Least Absolute Deviations)**. Le risque empirique : `R_emp(θ) = Σ |yᶦ − θᵀxᶦ|`

**Pourquoi L1 est plus robuste ?**

Avec L2, un résidu 3x plus grand est pénalisé 9x plus fort → un outlier tire fortement la droite vers lui. Avec L1, la pénalité est proportionnelle → l'influence d'un outlier est beaucoup plus limitée.

Sans outliers, L1 et L2 donnent des résultats très proches. La différence n'apparaît vraiment qu'en présence de valeurs aberrantes.

**Le revers :** L1 est non différentiable en 0, la surface du risque a des arêtes → pas de solution analytique → optimisation numérique nécessaire (plus lente).

|  | **L2** | **L1** |
| --- | --- | --- |
| Pénalisation | Quadratique | Linéaire |
| Robustesse aux outliers | Faible | Forte |
| Surface du risque | Bol lisse | Arêtes |
| Solution | Analytique (OLS) | Numérique |
| Vitesse | Rapide | Plus lente |

---

## Flexibilité : fonctions de base et régression polynomiale

Le modèle linéaire peut être étendu sans changer de cadre. Forme générale avec **fonctions de base** :

```
f(x) = θ₀ + Σ θⱼ φⱼ(x)
```

Les φⱼ peuvent être n'importe quelle transformation : x², x³, sin(x), √x, max(0,x)... Le modèle reste **linéaire en θ** → OLS fonctionne toujours, avec la même formule `θ̂ = (XᵀX)⁻¹Xᵀy`.

**Régression polynomiale** : cas particulier où φₖ(x) = xᵏ

```
f(x) = θ₀ + θ₁x + θ₂x² + … + θ_d x^d
```

On construit X = [1, x, x², ..., x^d] et θ ∈ ℝ^{d+1}.

---

## Compromis flexibilité / surapprentissage

Augmenter le degré d enrichit H et donne plus de capacité au modèle. Mais trois problèmes apparaissent :

- **Bruit :** un modèle trop flexible apprend aussi le bruit des données, pas seulement le signal
- **Surapprentissage :** grande capacité → mauvaise généralisation sur de nouvelles données
- **Oscillations (phénomène de Runge) :** degré élevé → instabilité et oscillations aux bords

Exemple concret (bike rental) : l'erreur test est minimale pour d = 3. En dessous → underfitting, au-dessus → overfitting. **Choisir la bonne complexité = compromis biais/variance.**

---

## Ce qu'il faut retenir

- Régression linéaire = ERM avec H linéaire et loss L2
- L2 → SSE → solution analytique OLS : `θ̂ = (XᵀX)⁻¹Xᵀy`
- OLS = projection orthogonale de y sur l'espace colonne de X
- L1 plus robuste aux outliers mais pas de solution fermée
- Le modèle peut être non linéaire en x tout en restant linéaire en θ → OLS fonctionne toujours
- Plus flexible ≠ meilleur : compromis biais/variance à gérer
