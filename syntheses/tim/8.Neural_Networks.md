## Slides 419–429 — Introduction au Deep Learning

### Slide 419 — Qu’est-ce que le Deep Learning ?

Le deep learning est un **sous-domaine du Machine Learning**, lui-même sous-domaine de l’Intelligence Artificielle. Il repose sur les **réseaux de neurones artificiels**. La relation est donc : IA ⊃ ML ⊃ DL.

### Slide 420 — Pourquoi maintenant ?

Le deep learning n’est pas une idée nouvelle : les réseaux de neurones existent depuis les années 70, et les réseaux profonds (avec plusieurs couches cachées) ne sont guère plus récents. Ce qui a changé, c’est la conjonction de quatre facteurs qui ont rendu le DL explosif :

Un **matériel spécialisé et puissant** (GPU, TPU) permet aujourd’hui d’entraîner des réseaux énormes sur des problèmes difficiles. Une **quantité massive de données** est disponible — ce que le DL consomme voracement. Des **architectures spécifiques** ont été développées pour les images (CNN) et le texte (RNN, Transformers). Enfin, de **meilleures stratégies d’optimisation et de régularisation** ont émergé.

### Slides 421–424 — Image Classification avec des réseaux de neurones

La définition de Bengio résume l’idée : le DL repose sur l’apprentissage de **multiples niveaux de représentation et d’abstraction**. Concrètement, au lieu de donner manuellement des features à un classifieur, on laisse le réseau apprendre lui-même des représentations intermédiaires à partir des données brutes — par exemple des pixels.

Le réseau prend une image en entrée, la transforme couche après couche à travers des représentations de plus en plus abstraites, et produit une prédiction en sortie (“oiseau” ou “pas oiseau”). La magie — et c’est le cœur du DL — c’est que ces représentations intermédiaires sont **apprises automatiquement** depuis les données.

### Slide 425 — Quand utiliser le Deep Learning ?

Le DL est particulièrement efficace quand les données ont ces propriétés : elles sont **haute dimensionnelles**, les features individuelles ne sont **pas très informatives seules** (c’est leur combinaison qui compte), et il y a une **grande quantité de données d’entraînement**.

Conséquence importante : **pour des données tabulaires classiques, le DL est rarement le bon choix**. Sans tuning extensif, des modèles comme les Random Forests ou le Gradient Boosting surpassent généralement le DL sur ce type de données. Une exception : les données catégorielles avec beaucoup de niveaux.

### Slides 426–430 — Use-cases : Images

Les images sont un cas d’usage idéal pour le DL. Une image couleur 255×255 représente déjà 195 075 features. Un pixel seul n’a pas de sens — c’est leur agencement qui porte l’information. Et pour beaucoup d’applications, des quantités massives d’images sont disponibles. L’architecture adaptée aux images est le **CNN (Convolutional Neural Network)**.

Trois tâches types sur images :
- **Image classification** : prédire un label unique par image (ex : CIFAR-10, 60 000 images 32×32 en 10 classes).
- **Object detection** : détecter et localiser des objets dans une image (ex : Mask R-CNN, qui génère aussi des masques de segmentation par instance).
- **Image segmentation** : partitionner l’image en segments (pixel par pixel).

### Slides 431–433 — Use-cases : Texte

Le texte partage les mêmes propriétés favorables au DL : haute dimensionnalité (chaque mot peut être une feature — 300 000 mots en allemand), features peu informatives isolément, et données massives disponibles. L’architecture adaptée est le **RNN (Recurrent Neural Network)**.

Deux tâches types sur texte :
- **Sentiment Analysis** : classification du texte selon l’opinion exprimée (positif / neutre / négatif), en utilisant du NLP pour extraire l’information émotionnelle et subjective.
- **Machine Translation** : traduction automatique neuronale (type Google Translate), qui modélise la probabilité d’une séquence de mots en traitant des phrases entières dans un modèle intégré.

### Slide 434 — Use-case : Parole

La **reconnaissance et génération de la parole** (ex : Google Assistant) est un autre domaine phare. Le réseau extrait des features depuis les données audio pour des tâches en aval, comme la classification d’émotions dans la voix.

## Slides 435–445 — Le Neurone Unique (Perceptron)

### Slide 435 — Introduction : Single Neuron / Perceptron

Cette section pose les bases : un neurone artificiel unique, ses composants, son espace d’hypothèses et ses fonctions de perte.

### Slide 436 — Structure d’un neurone

Le **perceptron** est l’unité computationnelle de base d’un réseau de neurones. Il prend en entrée un vecteur de features x = (x₁, …, xₚ), associe à chaque feature un **poids** wⱼ, ajoute un **biais** b, et applique une **fonction d’activation** τ à la somme pondérée :

```
f(x) = τ(w₁x₁ + ... + wₚxₚ + b) = τ(wᵀx + b)
```

Graphiquement : les features sont des nœuds dans la **couche d’entrée (input layer)**, les poids sont des arêtes, et la computation τ(zᵢₙ) est représentée par le nœud de **sortie (output layer)**. Le biais b est souvent absorbé dans le vecteur de poids en ajoutant une feature constante égale à 1.

### Slide 437 — Espace d’hypothèses d’un neurone

La fonction d’activation choisie détermine ce que le neurone peut apprendre :

- Avec la **fonction identité** (τ(v) = v), on obtient exactement une **régression linéaire**.
- Avec la **fonction logistique** (sigmoid), on obtient exactement une **régression logistique**.

Un neurone unique, c’est donc juste une façon graphique de représenter des modèles déjà connus.

### Slides 438–442 — Forward pass

Le flux de calcul dans un réseau va de gauche à droite : on “nourrit” le vecteur d’entrée aux neurones de gauche, et les computations s’enchaînent jusqu’à la sortie. C’est ce qu’on appelle le **forward pass**.

Un neurone effectue un calcul en **deux étapes** :
1. **Transformation affine** : somme pondérée des entrées plus le biais → zᵢₙ = wᵀx + b
2. **Activation non-linéaire** : application de τ à zᵢₙ → f(x) = τ(zᵢₙ)

### Slide 443 — Hypothèse space et optimisation

L’espace d’hypothèses d’un neurone unique est :

```
H = { f : Rᵖ → R | f(x) = τ(Σⱼ wⱼxⱼ + b), w ∈ Rᵖ, b ∈ R }
```

Pour l’optimiser, on minimise le **risque empirique** (ERM) :

```
Remp = (1/n) Σᵢ L(y⁽ⁱ⁾, f(x⁽ⁱ⁾))
```

Selon la tâche, la loss change :
- **Régression** → L2 loss : L(y, f(x)) = ½(y − f(x))²
- **Classification binaire** → Cross-entropy (Bernoulli loss) : L(y, f(x)) = −(y log f(x) + (1−y) log(1−f(x)))

> **Notes de cours** : On retrouve ici les équivalences vues précédemment dans le cours : le Brier Score correspond au Gini, et la log-loss correspond à l’entropie. Le cadre ERM est le fil conducteur.
> 

Pour un neurone unique avec sigmoid ou identité, la loss est **convexe** — l’optimum global est trouvable par descente de gradient. Un neurone unique entraîné avec sigmoid + Bernoulli loss jusqu’à convergence donne exactement le même résultat que la régression logistique classique.

## Slides 446–467 — Réseaux avec une couche cachée

### Slide 446 — Introduction : Single Hidden Layer Networks

Cette section introduit l’idée clé qui justifie le deep learning : ajouter des couches cachées pour apprendre des **représentations intermédiaires**.

### Slides 447–451 — Motivation : pourquoi des couches cachées ?

Un neurone unique ne peut apprendre que des **frontières de décision linéaires**. Sur des données non séparables linéairement (ex : points disposés en cercle), il échoue.

Mais si on transforme d’abord les features dans un nouvel espace (ex : passage de coordonnées cartésiennes à polaires), la séparation linéaire devient possible. Le principe : **au lieu de classifier dans la représentation originale, on classifie dans un nouvel espace de features**.

C’est exactement ce que fait une couche cachée : elle apprend automatiquement cette transformation. Avant le DL, ces transformations étaient faites à la main par des experts du domaine — c’est le **feature engineering**. Le DL automatise cette étape : c’est le **representation learning**.

### Slide 452 — Architecture d’un réseau à une couche cachée

Un réseau à une couche cachée (sans compter la couche d’entrée) se compose de :

1. **Couche cachée (hidden layer)** : un ensemble de neurones, chacun appliquant une transformation affine puis une activation non-linéaire sur les inputs.
2. **Couche de sortie (output layer)** : un ou plusieurs neurones de sortie.

Plusieurs inputs sont simultanément envoyés au réseau. Chaque neurone de la couche cachée reçoit tous les inputs. Le résultat de la couche cachée devient l’input de la couche de sortie.

### Slides 453–462 — Exemple de forward pass complet

Prenons un réseau avec 3 inputs (x⁽¹⁾ = -3, x⁽²⁾ = 1, x⁽³⁾ = 5) et 4 neurones cachés.

**Étape 1 — Transformation affine dans la couche cachée :**

Chaque neurone j calcule zⱼᵢₙ = Σᵢ wᵢⱼ · x⁽ⁱ⁾ + bⱼ. Dans l’exemple des slides :

```
z⁽¹⁾ᵢₙ = 3·(-3) + (-9)·1 + 2·5 + 5 = -3
z⁽²⁾ᵢₙ = 11·(-3) + (-2)·1 + 7·5 + 2 = 2
z⁽³⁾ᵢₙ = (-6)·(-3) + 3·1 + (-4)·5 - 1 = 0
z⁽⁴⁾ᵢₙ = 6·(-3) + (-1)·1 + 5·5 + 1 = 7
```

**Étape 2 — Activation non-linéaire (sigmoid) dans la couche cachée :**

```
z⁽ⁱ⁾ₒᵤₜ = σ(z⁽ⁱ⁾ᵢₙ) = 1 / (1 + e^(-z⁽ⁱ⁾ᵢₙ))
```

Ce qui donne : z⁽¹⁾ₒᵤₜ = 0.05, z⁽²⁾ₒᵤₜ = 0.88, z⁽³⁾ₒᵤₜ = 0.50, z⁽⁴⁾ₒᵤₜ = 0.99

**Étape 3 — Transformation affine dans la couche de sortie :**

```
fᵢₙ = u₁·0.05 + u₂·0.88 + u₃·0.50 + u₄·0.99 + c
fᵢₙ = 3·0.05 + (-12)·0.88 + 8·0.50 + 1·0.99 + 6 = 0.57
```

**Étape 4 — Activation de sortie :**

```
fₒᵤₜ = σ(0.57) = 1 / (1 + e^(-0.57)) = 0.64
```

La prédiction finale du réseau est **0.64** (probabilité d’appartenir à la classe positive).

### Slides 463–464 — Fonctions d’activation dans la couche cachée

Si la couche cachée n’utilise **pas** d’activation non-linéaire, le réseau entier reste une fonction linéaire — l’empilage de couches ne sert à rien. La non-linéarité est donc indispensable.

Deux fonctions d’activation typiques pour les couches cachées :

**ReLU (Rectified Linear Unit)** — la plus populaire actuellement :

```
σ(v) = max(0, v)
```

Elle vaut 0 pour les valeurs négatives, et est égale à v pour les valeurs positives. Simple, efficace, rapide à calculer.

**Sigmoid** :

```
σ(v) = 1 / (1 + exp(-v))
```

Peut aussi être utilisée dans les couches cachées, bien que ReLU soit préféré en pratique.

### Slide 465 — Vers la classification multi-classe

Ce slide introduit la section suivante : les réseaux à couche cachée unique pour la **classification multi-classe**. L’architecture générale reste la même, mais la couche de sortie aura **plusieurs neurones** (un par classe), et la fonction d’activation de sortie sera la **Softmax** (au lieu de sigmoid). La loss utilisée sera la **Softmax loss** (cross-entropy généralisée).
